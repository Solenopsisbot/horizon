# Java mod compatibility checklist

Status: active work for Minecraft 26.3. The implementation is tracked in [issue #6679](https://github.com/horizon-rust/horizon/issues/6679). This page is the short progress view; [java-mod-compat.md](java-mod-compat.md) remains the design and phase plan.

Last checked: 3 November 2026, commit `0cb1465ce`.

## Supported now

- [x] Read Fabric `fabric.mod.json`, NeoForge `neoforge.mods.toml`, and legacy Forge `mods.toml` for bounded identity, dependencies, client-only markers, and entrypoint discovery.
- [x] Discover and run multiple Fabric entrypoints in deterministic order.
- [x] Discover NeoForge and legacy Forge `@Mod` classes through the native probe path.
- [x] Run unsupported entrypoints through the embedded JVM runner as a fallback.
- [x] Expose bounded Fabric loader values: loaded-mod checks, metadata (including authors/contributors/license collections and icon-path optionals), versions, environment type, development marker, root paths, seeded containers, and identity `MappingResolver` queries.
- [x] Expose bounded NeoForge and legacy Forge loader values: mod lists, containers, event-bus access, mod ids, and role-aware client/server selection.
- [x] Register and inspect bounded NeoForge and Forge deferred registrations, holders, registry objects, keys, ids, entry collections, generated `Registry.getHolder`/`getOrThrow` lookups, explicit typed-registration handoff, typed recipe and ingredient data-file declarations, `Item.Properties` stack/durability/crafting-remainder/fire-resistance values, bounded `BlockBehaviour.Properties` strength/resistance/friction/occlusion/tool/random-tick values, `EntityType.Builder` category/dimensions and mob lifecycle values, and `ItemStack.getUseAnimation`/tag-stream façade coverage, and custom payload type identity.
- [x] Record Fabric events, NeoForge events, and legacy Forge event-bus listeners with ordering, cancellation markers, unregister support, and Forge `register(Object)` handlers.
- [x] Record custom payload registrations for the supported Fabric/NeoForge directions, retain custom payload type identity, and support the bounded legacy Forge `SimpleChannel.registerMessage` alias, with bounded `FriendlyByteBuf` value round trips, including enum, nullable, primitive, byte-array, UUID, optional, and cursor payloads.
- [x] Provide bounded NeoForge and legacy Forge capability/`LazyOptional` markers, NBT values, identifiers, resource keys (including `ResourceKey.location`), capability `orEmpty` values, bounded declared-field reflection, arrays, reflection metadata, collections (including `removeIf` and `Iterator.forEachRemaining`), maps (including `entrySet`/`Map.Entry` equality and hashing, `computeIfPresent`, and `merge`), primitive optionals (`OptionalInt`, `OptionalLong`, `OptionalDouble`), streams (including runtime-owned `toArray` results and `Collectors.toList/toSet`), and optionals.
- [x] Provide common Java wrapper/string/collection operations used by loader bootstrap code, including integer/long/float/double/byte/short/character conversion, `Number` accessors, checked math, seeded `System.currentTimeMillis`/`identityHashCode`, seeded `System.getProperty(key, default)` and `System.getenv` queries, deterministic `Thread.currentThread`/`getName`/`isDaemon`/`getContextClassLoader` markers, bounded callback combinators, `Arrays.asList`, `Objects.hashCode`/`requireNonNullElse`, and a restricted `String.format` subset.
- [x] Provide bounded `ClassLoader.getResource`/`getResourceAsStream`/`getResources` markers from explicitly seeded `StdHost::with_resource` entries and every non-class file bundled in a `NativeJar::seed_host` jar with bounded byte-backed `InputStream` reads, `available`, `skip`, `skipNBytes`, mark/reset, and close support, explicitly seeded `ClassLoader.loadClass` markers, current-jar `Class.forName`, bounded field reflection, and explicitly seeded `ServiceLoader` providers and iterators, and capability `orEmpty` values; these queries never scan host files or the process classpath.
- [x] Maintain deterministic Fabric jar fixtures covering entrypoint execution, seeded resources, typed registry declarations, unknown-kind diagnostics, an invokedynamic event listener dispatch, and the Horizon typed content adapter/content-planning path.
- [x] Maintain runtime-built Fabric, legacy Forge, and NeoForge fixtures covering `fabric.mod.json`, `mods.toml`, `@Mod` discovery, `DeferredRegister`, `SimpleChannel.registerMessage`, event-bus listener dispatch, Forge `register(Object)`/`unregister(Object)` handlers, and the game-facing `--java-mod` content path; role selection and typed-registration merge behavior are also covered.
- [x] Preserve bounded Throwable/Exception/Error messages and cause markers, including `getMessage`, `getCause`, `initCause`, and `toString` diagnostics.
- [x] Mirror the common `Locale.US` integer grouping path used by the native statistics screen without emulating arbitrary locale patterns.
- [x] Generate and test the Java façade, including bounded public Mixin `@Accessor`/`@Invoker` stubs, array-returning signatures, common `Identifier` prefix/language-key/ordering helpers, Holder serialization queries, TagKey values, `HitResult`/`BlockHitResult` state and copy factories, bounded `FluidState` queries, bounded `EntityType.Builder` and `MobCategory` values, bounded `Item.Properties` stack/durability/crafting-remainder/fire-resistance values, bounded `BlockBehaviour.Properties` strength/occlusion/tool/random-tick/movement values, `InteractionHand` name/opposite semantics, and the sealed 26.3 `InteractionResult` value records and constants.
- [x] Maintain a class/member/Mixin census with native hook matching, config target discovery, Mixin `@At` values and bounded `args` selectors, deterministic report-only `mixin_translation_plans` operation families and match reasons, report-only `@Group` constraints, slice boundary/value preservation, top-level and nested `injectors` config edge values, and Mixin Extras injector normalization, loader ABI classification, access-widener/access-transformer discovery (including access-widener namespaces), Mojang support-API façade classification, and explicit report-only diagnostics.

## Partial or report-only

- [ ] Full Mixin weaving. Native execution now covers ordered chains of void-only non-cancellable `@Inject(at = HEAD)`, `RETURN`, and `TAIL` callbacks with mirrored arguments, invoking the target body once; return-value callbacks, other anchors, mixed anchors, and cancellation remain JVM fallback. Single-hook empty-`@At` overwrites are emitted as executable replacement plans. The census reads config targets, injection annotations, `@At`, plugins, refmaps, and access metadata; it does not execute plugins, apply access changes, or rewrite bytecode.
- [ ] Unmatched Mixin injection points. They are listed under `hook_points` with an empty `native_hooks` array and counted in `points_report_only`.
- [ ] Java registration markers. Explicit `META-INF/horizon-native.json` declarations and registrations enriched through `StdHost::attach_registration_declaration` now cross the typed sink for blocks/items/effects/recipes/ingredients plus entities, data components, attachments, and bounded custom rows; the server thread now atomically snapshots sorted blocks/items/entities/data-components/attachments with typed templates/declarations and applies mob effects through a bounded helper; full live object/table synchronization remains incomplete.
- [ ] JVM fallback coverage. Unsupported native calls, dynamic classpath failures, and reflective or incompatible missing façade members now have explicit diagnostics; the JVM path still needs broader loader façades and real-mod fixtures.
- [ ] Java classpath discovery. The census reports `ServiceLoader`, arbitrary `ClassLoader` loading, and `Class.forName` as dynamic diagnostics. Native `ServiceLoader.load`/`loadInstalled`, `ClassLoader.loadClass`, and current-jar `Class.forName` now support only explicitly bounded values; arbitrary external discovery and resources outside the loaded jar remain report-only.

## Remaining work

- [ ] Build an ABI corpus from representative Fabric, Forge, and NeoForge jars and rank missing calls by execution frequency.
- [ ] Define the Mixin translation pipeline: resolve config targets, apply priority/order and cancellation, map supported injectors to Horizon hooks, and keep a JVM fallback for unsupported transforms.
- [ ] Add broader real-mod integration fixtures for registries, networking, capabilities, entities, menus, resource loading, and client/server separation; current fixtures cover client/server role rejection and typed content merging.
- [ ] Connect translated callbacks to the generated typed native API and complete live registry synchronization across Horizon's server-thread and dedicated-server boundaries; integrated-server startup now runs bounded Java entrypoints with role diagnostics.
- [ ] Complete live content registration and registry synchronization for code-declared blocks, items, entities, data maps, attachments, and custom ingredients.
- [ ] Expand client compatibility for HUDs, key mappings, tooltips, models, renderers, particles, screens, and shader-facing code.
- [ ] Add dedicated-server performance measurements, crash isolation, permissions, and a clear unsupported-call report in the launcher; bounded dedicated Java loading and role-specific failures now exist.
- [ ] Define the distribution policy for Java jars, native translations, signatures, and per-mod compatibility levels.

## Validation snapshot

- `horizon-native-java`: 108 unit tests passing, including bounded jar-resource stream reads and cursor operations, compiled HEAD/RETURN/TAIL injector fixtures and overwrite replacement execution, Fabric `MappingResolver` identity queries, plus runtime-built Fabric, Forge, NeoForge, Fabric-event, and Forge-event fixtures, including seeded class loading, current-jar reflection and bounded field metadata, TagKey values, bounded primitive optionals, custom payload type identity, `Number` accessors, callback combinators, restricted string formatting, deterministic Thread markers, Throwable metadata, and explicit ServiceLoader provider boundaries, and bounded Map.Entry equality/hashing.
- `horizon-mods`: 36 unit tests passing, plus the runtime-built typed declaration adapter fixture.
- `horizon-port-pack`: 177 unit tests passing, including bounded Item.Properties and BlockBehaviour.Properties façade values, Mixin `@At`/slice boundary metadata and values (including descriptor-bearing `@At(target:...)` selectors), config edge values, Mixin Extras injector normalization, loader ABI classification, Mojang codec/datafixer ABI coverage, native declaration-kind reporting, deduplicated Mixin hook matching, Class.forName boundary diagnostics, Registry holder lookup bodies, Identifier façade bodies, sealed InteractionResult façade values, BlockHitResult state coverage, FriendlyByteBuf façade values, and descriptor normalization coverage.
- `horizon-jvm`: 12 unit tests passing, including explicit fallback labels, static-initialization fallback diagnostics, and NeoForge constructor-only entry selection.
- `horizon-client` game mod tests: 13 passing, including bundled-resource loading, typed content, client/server role selection, and client-only NeoForge rejection.
- Workspace check, full client clippy, compatibility-crate clippy, formatting, and `tools/native_java_smoke.py` passing with compiled OptionalLong/OptionalDouble paths.

Every compatibility commit should update this checklist when a surface moves between these sections and should include the focused test or probe that justifies the change.
